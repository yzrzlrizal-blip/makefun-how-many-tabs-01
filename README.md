How many tabs do you have open? This program answers with one honest number: **137** — the tabs open across this machine's browser windows right now. One number, digits only, nothing else. Specific rather than round, high enough to surprise, low enough to be a real person's real browser.

## Run it

```sh
python3 main.py
```

It writes `137` to `/output/entry.txt`.
